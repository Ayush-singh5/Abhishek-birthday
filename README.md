# Celebration Experience — Final

Interactive single-page birthday experience for Ananya.

## Run locally
```powershell
python -m http.server 5500
```
Open `http://localhost:5500` from this project folder.

## Media
Keep the existing photos in `assets/images/` and your chosen music at:
`assets/audio/music.mp3`

## Main customization file
Edit `config.js` for recipient name, story text, image paths, audio settings, typing speed, and interaction timings.

## Final build notes

This final build preserves the approved experience and adds deployment-support files:
- `favicon.svg`
- `site.webmanifest`
- `404.html`
- `robots.txt`
- `DEPLOYMENT.md`

The approved scene choreography, animation timings, photo layout, typewriter speed, and reveal pacing are preserved.
